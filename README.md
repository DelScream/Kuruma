# KURUMA / 黒鉄

Концепт-лендинг вымышленного музея японской автомобильной культуры.

**CONCEPT PROJECT / FICTIONAL MUSEUM**

Сайт: [delscream.github.io/Kuruma](https://delscream.github.io/Kuruma/)

## Стек

Vite · React · GSAP · Lenis

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Фотографии

Все кадры отдаются с GitHub Pages из `public/images/`. Внешний CDN не используется: Unsplash с части сетей не открывается и оставляет пустые блоки.

Атмосферные кадры лежат в `public/images/stock/`. Карточки автомобилей — в `public/images/cars/`. Чтобы заменить снимок, сохраните JPG с тем же именем:
